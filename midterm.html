Week 1

Computational Complexity

How algorithm cost grows as input size grows.

Computational Complexity
Computational complexity measures the resources an algorithm requires as the input size increases.
Remember: resources = mainly time and space.
Input Size (n)
n represents the size or number of elements in the input data.
Time Complexity
Time complexity describes how the number of operations performed by an algorithm grows as the input size n grows.
Space Complexity
Space complexity describes how much memory an algorithm requires as the input size increases.
Asymptotic Complexity
Asymptotic complexity describes the growth of an algorithm for very large input sizes while ignoring constants and lower-order terms.
Example: n² + 100n + 1000 → n².
Big O — O
Big O gives an upper bound on the asymptotic growth of an algorithm.
Memory: O = at most / no faster than.
Big Omega — Ω
Big Omega gives a lower bound on the asymptotic growth of an algorithm.
Memory: Ω = at least.
Big Theta — Θ
Big Theta gives a tight bound, meaning the upper and lower asymptotic bounds have the same growth rate.
Memory: Θ = exact asymptotic order.
Constant Time — O(1)
Constant time means the number of operations does not depend on the input size.
Logarithmic Time — O(log n)
Logarithmic time occurs when each step reduces the remaining problem by a constant factor.
Linear Time — O(n)
Linear time means the number of operations grows directly with the input size.
Quadratic Time — O(n²)
Quadratic time means the number of operations grows approximately as the square of the input size.
Week 2

Arrays & Linked Lists

Linear data structures and how they use memory.

Array
An array is a collection of elements stored in consecutive memory locations and accessed using an index.
Key fact: direct index access is O(1).
Index
An index is a position number used to access an element in an array.
One-Dimensional Array
A one-dimensional array stores elements in a single sequence and uses one index.
Multidimensional Array
A multidimensional array uses two or more indices to organize data into multiple dimensions such as rows and columns.
Row-Major Order
Row-major order stores all elements of one row consecutively before storing the next row.
Course fact: C/C++ uses row-major order.
Column-Major Order
Column-major order stores all elements of one column consecutively before storing the next column.
Static Array
A static array has a fixed size determined at compilation time.
Dynamic Array
A dynamic array has memory allocated at run time, so its size can be chosen while the program is running.
Jagged Array
A jagged array is an array of arrays whose rows can have different lengths.
Linked List
A linked list is a collection of nodes connected using pointers.
Difference: nodes do not need to be adjacent in memory.
Node
A node is an element of a linked list that stores data and one or more pointers to other nodes.
Head
The head is a pointer to the first node of a linked list.
Tail
The tail is a pointer to the last node of a linked list.
Singly Linked List
A singly linked list is a linked list in which each node stores data and a pointer to the next node.
Last node: next points to NULL.
Doubly Linked List
A doubly linked list is a linked list in which each node has pointers to both the next and previous nodes.
Circular Linked List
A circular linked list is a linked list in which the last node points back to the first node instead of pointing to NULL.
Circular Array / Ring Buffer
A circular array is an array that logically connects the end back to the beginning so unused positions can be reused.
Sparse Table
A sparse table is a table in which most possible positions contain no useful data.
StructureMain exam idea
ArrayFast random access O(1), compact memory, but middle insertion/deletion may require shifting.
Linked listDynamic size and easy pointer-based insertion/deletion, but no direct random access and extra pointer memory.
Week 3

Stacks, Queues & Priority Queues

Stack
A stack is a linear data structure that follows the Last In, First Out (LIFO) principle.
Memory: last item inserted is the first removed.
Push
Push inserts a new element onto the top of a stack.
Pop
Pop removes the element from the top of a stack.
Top / Peek
Top or peek returns the top element of a stack without removing it.
LIFO
LIFO means Last In, First Out: the most recently inserted element is removed first.
Queue
A queue is a linear data structure that follows the First In, First Out (FIFO) principle.
Enqueue
Enqueue inserts an element at the rear of a queue.
Dequeue
Dequeue removes an element from the front of a queue.
FIFO
FIFO means First In, First Out: the element inserted first is removed first.
Priority Queue
A priority queue is a queue in which elements are removed according to priority rather than only their arrival order.
Heap
A heap is a complete binary tree that satisfies a heap-order property between every parent and its children.
Max Heap
A max heap is a heap in which every parent is greater than or equal to its children.
Therefore: the largest value is at the root.
Min Heap
A min heap is a heap in which every parent is less than or equal to its children.
Therefore: the smallest value is at the root.
Week 4

Trees, BST, AVL & Heaps

Tree
A tree is a hierarchical data structure consisting of nodes connected by edges.
Root
The root is the top node of a tree and has no parent.
Parent
A parent is a node that has one or more child nodes.
Child
A child is a node directly connected below another node.
Leaf
A leaf is a node that has no children.
Path
A path is a sequence of connected nodes from one node to another.
Level
The level of a node is its path length from the root plus one.
Course convention: root is level 1.
Height
The height of a tree is the length of the longest path from the root to a leaf.
Course convention: count edges/arcs, so a single-node tree has height 0.
Binary Tree
A binary tree is a tree in which each node has at most two children.
Binary Search Tree (BST)
A Binary Search Tree is a binary tree in which all values in the left subtree are smaller than the node and all values in the right subtree are greater.
Memory: LEFT < NODE < RIGHT.
Tree Traversal
Tree traversal is the process of visiting every node in a tree in a particular order.
Pre-order Traversal (VLR)
Pre-order traversal visits the node first, then the left subtree, then the right subtree.
In-order Traversal (LVR)
In-order traversal visits the left subtree, then the node, then the right subtree.
Important: in-order traversal of a BST gives sorted order.
Post-order Traversal (LRV)
Post-order traversal visits the left subtree, then the right subtree, and finally the node.
Breadth-First Traversal
Breadth-first traversal visits nodes level by level.
Usually uses: a queue.
Depth-First Traversal
Depth-first traversal follows a branch as deeply as possible before returning to explore other branches.
Deletion by Copying
Deletion by copying replaces the deleted node's value with its predecessor or successor and then removes that easier node.
Deletion by Merging
Deletion by merging removes a node by joining its left and right subtrees while maintaining BST order.
Tree Rotation
A rotation is a local rearrangement of nodes used to change the shape of a tree while preserving BST order.
DSW Algorithm
The Day-Stout-Warren algorithm balances a BST by first converting it into a right-leaning backbone and then using rotations to form a balanced tree.
Complexity: O(n).
AVL Tree
An AVL tree is a self-balancing Binary Search Tree in which the height difference between the left and right subtrees of every node is at most one.
Balance Factor
The balance factor of a node is the height of its left subtree minus the height of its right subtree.
Valid: −1, 0, +1. Formula: BF = height(left) − height(right).
Splay Tree
A splay tree is a self-adjusting Binary Search Tree that moves recently accessed nodes toward the root using rotations.
Heapsort
Heapsort is a sorting algorithm that builds a heap and repeatedly removes the root to place elements into sorted order.
Expression Tree
An expression tree is a binary tree used to represent an arithmetic expression, where operators are internal nodes and operands are usually leaves.

Week 6

B-Trees & Tries

Multiway search structures designed especially for large data and disk access.

Multiway Tree
A multiway tree is a tree in which a node can contain multiple keys and have more than two children.
Rule: a node with k keys can have k + 1 child pointers.
B-Tree
A B-tree is a balanced multiway search tree designed to reduce disk accesses by storing multiple keys in each node.
Important: all leaves are at the same level.
Order (m) of a B-Tree
The order m of a B-tree is the maximum number of child pointers a node can contain.
Therefore: maximum children = m; maximum keys = m − 1.
B-Tree Insertion
B-tree insertion places the new key in the correct leaf and splits a node if it overflows, promoting a median key to the parent.
B-Tree Split
A B-tree split divides an overflowing node and promotes its median key to the parent.
Memory: median goes UP.
B* Tree
A B* tree is a variation of the B-tree that keeps nodes more densely filled by redistributing keys before splitting nodes.
Course figure: at least about 2/3 full.
B** Tree
A B** tree is a B-tree variation that maintains nodes at approximately three-quarters full.
B+ Tree
A B+ tree is a B-tree variation in which actual records are stored in the leaf nodes while internal nodes are used as indexes.
Important: leaf nodes are linked, which supports efficient ordered traversal.
Prefix B+ Tree
A Prefix B+ tree stores only enough of each key in internal index nodes to distinguish between branches.
Bit Tree
A bit tree uses distinguishing bits from keys to determine which branch should be followed during a search.
Trie
A trie is a tree that searches for keys by using successive parts of the key, such as one character or bit at each level.
Idea: keys with the same prefix share part of the path.
Best exam technique: if the question says Define X, write the one-sentence definition first. Then add one key property or tiny example only if you have time. Do not replace a definition with only an example.
